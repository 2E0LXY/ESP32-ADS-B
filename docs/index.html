FIRST-TIME SETUP · ESP32-S3

Install over USB, directly from your browser.

Connect the Waveshare ESP32-S3 3.2-inch display, choose its USB serial port, and install the complete factory firmware. Nothing needs to be downloaded or unpacked first.

READY TO FLASH

Firmwarev2.4.0
Web Serial is not available here. Open this page in desktop Chrome or Microsoft Edge.USB access needs this secure GitHub Pages address. Do not open a saved local copy.
Use a data-capable USB cable in Chrome or Edge on a desktop computer.
Factory install: this erases existing Wi-Fi, API keys, location, map zoom, display mode, and admin password.
01

Connect USB

Use the board's USB port and a cable that supports data, not charge-only.

02

Start install

Select Connect & install, then choose the Espressif USB/JTAG or serial device.

03

Enter boot mode

If prompted, hold BOOT, tap RESET, then release BOOT and retry the connection.

04

Configure Wi-Fi

After flashing, follow the screen. Join ADSBMAP only if normal Wi-Fi cannot connect.

Already running this firmware? Use the device web interface's Firmware section or its flashing GitHub update button. Those OTA paths preserve saved settings. The USB installer is the recovery and first-install route.
Security: the firmware is built from this public repository by GitHub Actions. Release checksums remain available beside each firmware release.
