One worker, with the cache in its own memory. That is the right setup for a single vCPU and it is what the measured figures assume - a device poll costs about 7 ms, so one thread handles roughly 145 requests a second, and a receiver polls only every 30 s.

This cannot be switched on from here, and deliberately so. REDIS_URL and the worker count are read once when the process starts, so a button here could not do anything a restart would not have to do anyway. To enable it: uncomment REDIS_URL in .env, bring up the redis service, add --workers N to the uvicorn command in docker-compose.yml, then docker compose up -d --build. Only worth doing with more than one vCPU; this page will then say "Shared (Redis)" and show which worker is polling.
