Feed your own receiver into this system

Already run a physical receiver (readsb, dump1090, PiAware) feeding FlightAware, FlightRadar24, or similar? Point one more output at this server and two things happen: you get a live map of exactly what your own receiver sees, and those aircraft are added into the shared feed every device (including yours) can see - useful for local coverage the public APIs might miss. This is separate from the donated API keys below - this is your receiver's own raw data, not a key to someone else's network.
